# ASI Package Provenance

This package-local matrix was derived from the ASI v6.4 technology standard and
its v6.4 changelog. The matrix preserves the cited document and page references
so a policy owner can verify any decision against the controlled source
documents, which are not themselves redistributed here -- only the derived
matrix and its citations.

The standard is specific to this organization: it states which technologies and
versions are homologated for its own teams, and it is not general-purpose
guidance that would mean anything outside that context. That is a question of
scope, not of confidentiality, and it is exactly why this skill ships in DARQ
and not in the engine DARQ is built on -- see `docs/contrato-inclusion.md`.

When the standard is revised, this matrix is updated from the new controlled
source and its citations updated with it. The named owner recorded for this
content answers for that.
